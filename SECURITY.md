# Security Policy

## Public issues are not for vulnerabilities

Please do **not** report security vulnerabilities in public GitHub issues.

## Private disclosure path

Report vulnerabilities privately by email:

- **security@peopledex.app**

Include:

- A clear description of the vulnerability
- Steps to reproduce
- Affected app version/build
- Potential impact

## Response timeline

- Initial acknowledgment target: **within 2 business days**
- Triage/update target: **within 5 business days** after acknowledgment
- Remediation timeline depends on severity, exploitability, and release constraints

We appreciate responsible disclosure and coordinated reporting.
