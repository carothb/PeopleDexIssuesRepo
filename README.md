# PeopleDex Public Issue Tracker

This repository is a **public issue tracker only** for PeopleDex.

- It does **not** contain private application source code.
- It is intended for bug reports, release blocker tracking, and operational task tracking.

## Support scope

Use this repo to report issues related to:

- Android app behavior and regressions
- Firebase/App Check integration
- Google Play Billing and purchase flow
- PD Coins entitlement and usage flow

Out of scope:

- Security vulnerabilities (use private disclosure in `SECURITY.md`)
- Requests that require sharing secrets, tokens, or personal data

## Response expectations

- `priority:p0`: target first maintainer response within 4 business hours
- `priority:p1`: target first maintainer response within 1 business day
